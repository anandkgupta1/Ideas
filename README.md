# Ideas App 💡

A platform to share and like ideas, built with Laravel & MySQL.

## 🌐 Live Demo
👉 https://ideasapp.infinityfreeapp.com/

## 🛠️ Built With
- Laravel
- MySQL
- Bootstrap
- jQuery

## ⚙️ Installation
1. Clone the repo
   git clone https://github.com/anandkgupta1/Ideas.git
2. Install dependencies
   composer install
3. Copy .env.example to .env and update DB credentials
4. Run migrations
   php artisan migrate
5. Serve the app
   php artisan serve

## 📌 Features
- Share Ideas
- Like/Unlike Ideas ❤️
- Follow Users
- Feedback System
